## 二、阶段搜索覆盖矩阵(Search Coverage Matrix)

每个阶段在调用搜索前，必须先根据分析目标拆解需要补齐的信息维度。
以下矩阵定义了每个阶段的**必须覆盖维度**和对应的搜索方向。

**核心规则：**
- 矩阵中的维度是"必须尝试覆盖"，不是"必须搜到"——搜不到的信息如实标记为缺失，不得编造
- AI 在搜索前应将矩阵作为 checklist，搜索后对照矩阵检查覆盖完整性
- 缺少任意核心维度时，不得在 Convergence 中生成该维度的确定结论，
  只能标记为"信息缺失"或"有待补充"

### Stage 2 商业背景分析

搜索目标：理解赛道环境、行业周期、商业基础条件。

| 必须覆盖维度 | 搜索关键词方向 | 输出用途 |
|---|---|---|
| 市场规模 | XX行业市场规模、市场容量、行业规模 | 判断赛道空间 |
| 增长趋势 | XX行业近3年增长率、未来预测 | 判断增长阶段 |
| 生命周期 | 行业发展阶段、行业成熟度 | 判断进入窗口 |
| 政策环境 | 行业监管、政策要求、准入门槛 | 判断风险 |
| 消费趋势 | 消费趋势、用户需求变化、新兴场景 | 判断机会方向 |
| 渠道结构 | 线上渠道占比、线下渠道规模 | 判断销售路径 |
| 平台生态 | 小红书、抖音、淘宝、私域生态 | 判断流量入口 |
| 爆品路径 | XX品牌增长案例、爆款渠道 | 判断起盘方式 |

搜索结果需要回答的问题：
1. 这个市场够不够大？
2. 现在处于什么发展阶段？
3. 用户在哪里购买？
4. 新品牌通常如何进入？
5. 最大商业风险是什么？

### Stage 3 市场机会分析

搜索目标：判断品类机会、供需缺口、细分切入方向。

| 必须覆盖维度 | 搜索关键词方向 | 输出用途 |
|---|---|---|
| 品类规模 | XX品类市场规模、细分品类占比 | 判断品类天花板 |
| 品类增速 | XX品类增长率、新兴品类 | 判断品类生命周期 |
| 供需缺口 | XX品类用户痛点、未满足需求 | 判断市场空位 |
| 价格带分布 | XX品类价格区间、高端/大众占比 | 判断定价空间 |
| 用户画像 | XX品类用户画像、消费人群特征 | 判断目标用户 |
| 区域差异 | 一二线vs下沉市场、区域偏好 | 判断市场优先级 |
| 季节/周期 | 品类淡旺季、购买频次 | 判断运营节奏 |
| 替代威胁 | 替代品类、跨界竞争 | 判断品类风险 |

搜索结果需要回答的问题：
1. 这个品类的市场规模和增速是否值得进入？
2. 品类内是否存在未满足的需求？
3. 价格带是否存在空白区间？
4. 品类的核心用户是谁？
5. 最大的替代威胁来自哪里？

### Stage 5 竞争判断

搜索目标：理解竞争格局，寻找市场空位。

| 必须覆盖维度 | 搜索关键词方向 | 输出用途 |
|---|---|---|
| 品牌定位 | XX品牌定位、品牌理念、Slogan | 判断品牌差异 |
| 价格体系 | XX品牌价格、产品价格带 | 判断竞争区间 |
| 产品体系 | 爆款产品、明星单品、产品矩阵 | 判断竞争重点 |
| 核心卖点 | 产品卖点、用户评价 | 判断用户选择原因 |
| 视觉体系 | 品牌视觉、包装设计、官网、小红书主页 | 判断视觉机会 |
| 内容传播 | 小红书内容、抖音账号、营销案例 | 判断传播打法 |
| 用户好评 | 评论区好评、消费者好评总结 | 找用户认可的价值 |
| 用户差评 | 评论区差评、消费者投诉、未满足需求 | 找市场空位 |

搜索结果需要回答的问题：
1. 谁占据了市场？
2. 他们靠什么赢？
3. 用户为什么选择他们？
4. 用户哪里不满意？
5. 有没有未被满足的需求？
6. 如果我是新进入者，应该从哪个空位切入？

### Stage 8 内容规划

搜索目标：理解内容生态、用户兴趣、有效内容形式。

| 必须覆盖维度 | 搜索关键词方向 | 输出用途 |
|---|---|---|
| 平台生态 | 小红书/抖音/微信/ B站 品牌内容生态 | 判断主阵地 |
| 内容趋势 | XX品类内容趋势、热门话题 | 判断内容方向 |
| 用户兴趣 | XX品类用户关注话题、搜索热词 | 判断内容选题 |
| KOL生态 | XX品类达人、KOL合作案例 | 判断达人策略 |
| 内容形式 | 图文vs视频vs直播占比、爆款形式 | 判断内容类型 |
| 品牌案例 | XX品牌内容营销案例、爆款内容 | 借鉴成功路径 |
| 用户互动 | 评论互动、UGC内容、社群讨论 | 判断用户参与度 |

以下定义每个阶段的搜索覆盖维度最终写入哪个 Stage JSON 字段。
**核心原则**：搜索结果不直接进入报告，而是先进入 Stage JSON，成为战略推导的结构化依据。

#### Stage 2 搜索 → BusinessContext JSON

| 搜索覆盖维度 | 写入 BusinessContext JSON 字段 | 说明 |
|---|---|---|
| 市场规模 | `marketContext` 段落中引用 | 市场规模数据作为商业背景判断的支撑 |
| 增长趋势 | `marketContext` 段落中引用 | 增长趋势作为行业发展阶段的判断依据 |
| 生命周期 | `businessBackground` 段落 | 赛道阶段判断影响战略方向选择 |
| 政策环境 | `regulatoryContext`（如存在）或 `businessBackground` | 政策风险作为商业约束条件 |
| 消费趋势 | `marketContext` 段落中引用 | 趋势影响战略挑战的识别 |
| 渠道结构 | `marketContext` 段落中引用 | 渠道生态影响商业模式判断 |
| 平台生态 | `marketContext` 段落中引用 | 流量入口影响增长策略 |
| 爆品路径 | `strategicChallenge` 段落中引用 | 起盘方式影响竞争策略 |

| 季节/周期 | `categoryStatus` 段落中引用 | 运营节奏判断 |

| KOL生态 | `platformStrategy` 段落中引用 | 达人合作策略参考 |
| 内容形式 | `contentPillars[]` 段落中引用 | 图文/视频/直播占比 |

## 三、竞品搜索结构化卡片(Stage 5 专用)

Stage 5 搜索每个竞品时，不能只输出模糊的"A品牌很好"式总结。
必须将搜索结果整理为以下结构化卡片，确保 S5 的 competitiveGap 和
S5 的 competitiveGap 和 competitors[].opportunityGap 的每个判断都有可追溯的数据来源。

### 竞品卡片结构

```
┌─────────────────────────────────────────┐
│ 竞品名称: [品牌名]                        │
├─────────────────────────────────────────┤
│ 品牌定位: [一句话品牌定位，标注来源]         │
│ 目标用户: [核心用户画像，标注来源]           │
│ 价格带:   [价格区间，标注来源]              │
│ 明星产品: [1-3 款核心产品 + 卖点]           │
│ 核心卖点: [用户为什么买，标注来源]           │
│ 视觉特征: [包装/官网/社媒风格特征]           │
│ 内容策略: [社媒打法、内容类型、发布频率]      │
│ 用户好评: [好评主题总结，附 2-3 条原文摘录]   │
│ 用户差评: [差评主题总结，附 2-3 条原文摘录]   │
├─────────────────────────────────────────┤
│ 机会缺口: [该竞品没有覆盖的需求或场景]        │
│ 数据来源: [URL 列表]                      │
└─────────────────────────────────────────┘
```

### 竞品卡片使用规则

- 每个主要竞品一条卡片，至少覆盖 3 个竞品
- 每条信息必须标注来源(URL)，无法溯源的判断标记为"推测"
- "机会缺口"是该卡片最重要的字段——它直接为 S6 的差异化方向提供输入
- 用户好评和差评必须包含原文摘录，不能只写 AI 自己的总结——原文是后续 S4 消费者洞察的重要交叉验证材料
- 竞品卡片是 AI 内部工作文档，不直接进入报告正文。S5 Convergence 和 S6 Consultation 从卡片中提取结构化数据

## 四、Consultation 阶段:搜索结果展示格式(四段式，固定不变)

每次搜索完成后，必须按以下结构向用户展示，禁止隐藏搜索结果、
跳过展示直接提问、直接进入下一轮搜索：

---

**【搜索发现】**

- 名称/主题：
- 关键信息：
- 数据或结论：
- 来源：(使用 markdown 链接格式 `[来源名称](URL)`)

---

**【覆盖分析维度】**

本次搜索覆盖了以下维度：
- [x] 维度名称 — 已获取信息
- [x] 维度名称 — 已获取信息
- [ ] 维度名称 — 暂未覆盖

当前仍缺少的维度：
- xxx（原因：搜索范围内未找到相关信息 / 需要调整搜索方向 / 该维度信息需要用户补充）

> 此清单帮助 AI 判断搜索覆盖是否完整，避免搜了两份报告就认为分析完成。

---

**【可信度判断】**

已确认信息：(来自权威来源、官方数据、可靠媒体——列出具体信息和来源)

待验证信息：(来源不足、基于推断、缺少交叉验证——列出并说明为什么待验证)

---

**【对本阶段分析的影响】**

说明该发现是否改变当前判断：这个信息支持还是挑战了此前的假设？
是否需要进一步验证？验证什么？

---

只有完成以上展示后，才可以继续提问、继续搜索、或更新阶段判断。

如果搜索结果为空或不相关，如实告知："搜索了 [关键词]，未找到
相关信息。建议调整搜索方向或基于已有信息继续分析。"

## 五、证据分层规则(AI 内部分类用)

以下标注是 AI 的内部元数据，仅用于你在后续推理中判断信息可信度，
**严禁出现在任何用户可见的输出中**(包括搜索结果展示、对话回复、
确认总结的正文文本)。

- 来自官方统计、权威行业报告的数据 → 内部分类：fact
- 多来源交叉推断得出的判断 → 内部分类：inference
- 未找到直接证据、仅为策略假设 → 内部分类：hypothesis，不使用
  "已确认""明确显示"这类确定性措辞

### 向用户展示时的格式规则

向用户展示搜索发现时，证据信息应自然融入行文。
**禁止**在正文中使用 `evidenceLevel:`、`[verified]`、
`(证据等级：xxx)`、`可信度：` 等审计元数据标签。

✅ 正确：
  根据艾瑞咨询 2024 年宠物消费报告，该品类年增速约 18%
  36氪报道显示该方向近两年融资活跃
  该判断目前基于创始人单方面观察，有待后续市场分析阶段验证

❌ 错误：
  (来源：报告大厅，evidenceLevel: fact)
  (创始人自述…，evidenceLevel: inference)
  证据可信度：推测

## 六、Convergence 阶段:引用格式要求

- 引用搜索来源时，必须使用 markdown 链接格式内联 URL：
  `[来源名称](URL)`，不得只写来源名称不带链接
- 每条引用须在对应 JSON 字段的 `dataSources` 数组中记录来源、
  日期(如有)、摘要
- `dataSources` 属于审计元数据，不直接进入报告正文，由
  `assemble.ts` 决定是否以脚注形式呈现

## 七、阶段搜索完成条件(Search Completion Gate)

**这是防止"搜了两个报告就下结论"的关键约束。**

每个阶段在进入 Convergence 之前，AI 必须对照搜索覆盖矩阵检查：
搜索覆盖是否满足该阶段的最低要求？

### 完成判断规则

| 判断 | 条件 | 行动 |
|---|---|---|
| **可以进入 Convergence** | 所有核心维度均已尝试搜索(有结果 or 确认搜不到) | 收敛输出中明确标注哪些维度信息缺失 |
| **需要继续搜索** | 存在未尝试搜索的核心维度 | 继续搜索缺失维度，不得跳过 |
| **标记为信息缺失** | 已搜索但确实找不到相关信息 | 在 Convergence JSON 中该维度字段留空或标注"信息缺失"，不影响流程推进 |

### 各阶段最低覆盖要求

**Stage 2 商业背景分析：**

进入 Convergence 前，必须至少覆盖：
- [ ] 市场规模
- [ ] 增长趋势
- [ ] 生命周期判断
- [ ] 消费趋势
- [ ] 渠道结构
- [ ] 商业风险(政策/替代/竞争等至少识别一项)

若缺少任意核心维度：
- 该维度的分析结论不得生成为确定判断
- 在 BusinessContext JSON 对应字段中标注"基于有限信息"或"待补充"
- **不阻塞阶段推进**——信息不完整可以如实记录，但不得伪装成完整分析

**Stage 3 市场机会分析：**

进入 Convergence 前，必须至少覆盖：
- [ ] 品类规模
- [ ] 品类增速
- [ ] 供需缺口(至少尝试搜索用户痛点)
- [ ] 价格带分布

若缺少任意核心维度：
- 在 MarketInsights JSON 对应字段中标注"搜索范围内未找到"
- 不得虚构市场规模数据和增长率

**Stage 5 竞争判断：**

进入 Convergence 前，必须至少覆盖：
- [ ] 3-5 个主要竞品的竞品卡片(每个竞品至少填写定位、价格带、核心卖点、用户好评、用户差评)
- [ ] 价格带分布
- [ ] 定位差异(至少能区分各竞品的核心定位差异)
- [ ] 用户差评分析(至少 2 个竞品有差评原文摘录)
- [ ] 市场空位(至少识别一个未被竞品覆盖的需求或场景)

若缺少任意核心维度：
- 不得声称"已完成竞争格局分析"
- 缺少的竞品信息标记为"信息不足，有待补充"
- competitiveGap 和 competitors[].opportunityGap 字段如果缺少差评数据支撑，必须标注"基于有限竞品信息推导"

**Stage 8 内容规划：**

进入 Convergence 前，必须至少覆盖：
- [ ] 至少 2 个平台的生态特征
- [ ] 至少 2 个内容趋势或热门话题
- [ ] 至少 1 个品牌内容营销案例

### 信息缺失的正确处理

✅ 正确：
  "关于二三线城市高端宠物食品的渗透率，当前搜索范围内未找到相关数据。
  该维度在 MarketInsJSON 中标记为'待补充'，不影响其他维度的判断。"

✅ 正确：
  "竞品 C 的用户差评数据不足（仅找到 3 条有效评价），competitiveGap 中
  关于竞品 C 的缺口判断标注为'基于有限样本'。"

❌ 错误：
  "市场竞争格局清晰。"（只搜了 2 个竞品，未覆盖核心维度就下结论）

❌ 错误：
  "该品类年增长率约 25%"(未找到来源，AI 自己编的数字)

## 八、禁止事项(适用于全部四个阶段)

- 不得将搜索范围内未发现的内容，表述为"市场上不存在"，
  只能表述为"当前搜索范围内未发现"
- 不得为了凑齐信息而虚构搜索结果或来源
- 搜索结果质量不足时，如实告知置信度低，不得包装成确定结论
- 不得跳过搜索覆盖矩阵中的核心维度直接进入 Convergence
- 不得在核心维度信息缺失时生成确定结论——只能标注"信息缺失"或"有待补充"
- 不得将 AI 自己的推测量化为具体数字(如"约 500 亿市场规模""增速约 25%")，
  除非有明确来源支撑
