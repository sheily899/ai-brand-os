# 机会 4 前置分析：Prompt 模板去重

> 分析时间：2026-08-05 | 结论：🟢 可考虑，优先级一般

---

## 一、分析目标

验证"Prompt 模板去重"是否为真实 Token 瓶颈。

做法：将 8 个 consultation prompt 中的共享段落提取为公共 base，减少重复注入。

判定标准：

| 共享内容占比 | 结论 |
|------------|------|
| <20% | 不值得优化，收益有限 |
| 20-40% | 可考虑，优先级一般 |
| >40% | 值得重构，收益明显 |
| >50% | 高优先级优化 |

---

## 二、分析方法

1. 读取 8 个 consultation prompt 模板文件
2. 按空行分割为段落，MD5 hash 精确匹配 + 归一化匹配（去除 stage 特定词）
3. 统计每文件共享/独有 char 占比
4. 分类共享内容：规则 vs 方法论 vs 模板结构
5. 与真实 System Prompt token 数据交叉对比

## 九、判定

**🟢 可考虑，优先级一般**

- 模板内共享率 26.3%，在 20-40% 区间
- 但绝对收益小：全部 8 阶段共享内容合计仅 2,957 tokens
- 共享内容全部是操作流程描述（阶段退出机制 + 收尾语），不是专业知识
- 在真实 System Prompt 层面（含 DM+Search），共享只占 2-10%
- S2/S3/S8 的大 Prompt 是因为 DM Context + Search Context 膨胀
- **投入产出比不如机会 1（DM 分层）和机会 2（Search Context 压缩）**
